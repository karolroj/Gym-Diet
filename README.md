# G&D

Aplikacja **PWA** zbudowana w **.NET Blazor** z **Tailwind CSS**, łącząca w jednym miejscu funkcje **Fitatu** (dziennik żywienia, kalorie i makroskładniki) oraz **Hevy** (dziennik treningów siłowych).

## Założenia

- Śledzenie posiłków, kalorii i makroskładników (jak Fitatu)
- Planowanie i zapis treningów, serii, powtórzeń i ciężarów (jak Hevy)
- Jedna aplikacja zamiast dwóch, z wspólnym podsumowaniem diety i treningu
- PWA: instalacja na telefonie, działanie offline

## Stack

- .NET Blazor (PWA)
- Tailwind CSS
